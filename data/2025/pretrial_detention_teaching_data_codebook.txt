CODEBOOK: CRIMINAL JUSTICE EDA DATASET
======================================

This is a fictional dataset created for teaching purposes.
Each row represents one hypothetical criminal case.


VARIABLE: id
------------
Description: Unique case identification number
Values: 1–30


VARIABLE: age
-------------
Description: Age of the individual, in years
Values: 18–55


VARIABLE: gender
----------------
Description: Gender category
Values: Female, Male, Other


VARIABLE: neighborhood
----------------------
Description: Neighborhood where the individual resides
Values: North, South, West


VARIABLE: prior_arrests
-----------------------
Description: Number of prior arrests
Values: 0–5


VARIABLE: detained
------------------
Description: Whether the individual was detained before trial
Values:
  Yes = Detained before trial
  No  = Not detained before trial


VARIABLE: charge_level
----------------------
Description: Seriousness of the current charge
Values:
  1 = Misdemeanor
  2 = Low-level felony
  3 = Serious felony


MISSING DATA
------------
There are no missing values in this dataset.
